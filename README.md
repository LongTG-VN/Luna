# Luna AI Diary — V0

V0 landing page based on the Stitch direction.

## Fast preview
Open `index.html` directly in a browser.

## Next.js version
The `app/` directory contains a Next.js App Router implementation.
Run locally when npm access is available:

```bash
npm install
npm run dev
```

- Hero / Luna identity
- Meet Luna
- Latest Diary
- Little Moments gallery
- Social links
- Collaboration CTA
- Responsive desktop/mobile

V1 ideas: diary detail pages, CMS/Supabase, social stats, media kit, contact form.
